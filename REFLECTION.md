1. The user enters a possible webpage into the browser, then the browser sends the request to the DNS. The DNS translates the webpage into an IP address
   associated with that webpage (in this case the github page site). It goes through the network to the Github pages servers and searches for the repo its
   connected to. Once the HTML file is found, Github sends that HTML file back to the browser. If the browser sees in the HTML file that there are other
   files needed, it sends another request for those files. Once those are found, Github will respond back with those needed files and then the browser
   displays the content/webpage.
